# 🎓 Student Management System

A database-driven Student Management System built using **Python, Flask, MySQL, HTML, CSS, and Bootstrap**.

The application allows users to manage student records through a simple web interface with CRUD operations, search functionality, and a student dashboard.

## ✨ Features

- ➕ Add new students
- 📋 View all student records
- ✏️ Edit student information
- 🗑️ Delete student records
- 🔎 Search students by name, email, or course
- 📊 Display total number of students
- 💾 MySQL database integration
- 🔐 Secure database credentials using `.env`
- 📱 Responsive interface using Bootstrap
- 🧱 Object-oriented database management

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Backend programming |
| Flask | Web framework |
| OOP | Database management structure |
| MySQL | Database |
| mysql-connector-python | MySQL connectivity |
| HTML5 | Page structure |
| CSS3 | Styling |
| Bootstrap | Responsive UI |
| Jinja2 | Dynamic HTML templates |
| python-dotenv | Environment variable management |
